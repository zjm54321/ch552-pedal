# 验证范围

## 接受条件和证据

| 行为 | 最小证据 | 验证责任 |
|---|---|---|
| 环境独立 | 此目录的锁定 flake 可进入，SDCC / Make / 烧录工具版本可查 | 工具链实现者 |
| 固件可用于目标芯片 | 实际 SDCC 链接、HEX 生成、Flash 不越过 `0x3800`，USB buffer 与 XRAM 不冲突 | 固件实现者；主会话集成复核 |
| VIA 改键 | 协议响应、大小端、矩阵坐标、buffer 长度、非法请求和未知命令的主机测试 | 协议实现者 |
| 组合键 | 普通键、左右修饰键组合、按下/松开、按住时改键的成对报告测试 | 按键逻辑实现者 |
| 持久化 | 保存、重启读取、空白/损坏配置、无变化不重复写入的逻辑测试 | 持久化实现者 |
| 踩住上电进 ISP | 源码路径独立于键位加载；上电输入稳定判断；实物拔插验证 | 固件实现者；用户实物验收 |
| 双设备不串改 | 实机同时授权两块，分别改键并读回，两个设备分别输出和松开 | 用户实物验收 |
| 浏览器端可用 | 当前 VIA 加载匹配定义后识别、改键、读回，断电仍保持 | 用户实物验收 |

## 边界

未连接实物时，构建和逻辑测试不能替代 USB 枚举、ISP 或双设备网页联调。
任何烧录操作都需要明确选择设备和用户授权；默认构建、检查不访问 USB 设备。
沿用同一候选代码的有效证据，集成后只补齐受修改影响的检查。
